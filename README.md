# Neighbourly MVP v0.1

This is a mobile-first installable web prototype for the customer/community side of Neighbourly.

## Included
- Welcome/onboarding
- Local profile creation
- Customer home dashboard
- Browse community requests/offers
- Create a help request or offer
- My activity
- Wishlist/saved listings
- Start a message thread from a listing
- Safety centre and support/reporting placeholders
- Local persistence via localStorage
- PWA manifest + service worker

## Intentionally excluded from this version
- Worker dashboard (later update)
- Service Provider dashboard
- Admin dashboard
- Real ID document upload/verification
- Real authentication/backend/database
- Real-time chat
- Payments
- Push notifications
- GPS/location verification

## Run locally
Use any static file server in this directory, e.g. `python -m http.server 8000`, then open `http://localhost:8000`.
